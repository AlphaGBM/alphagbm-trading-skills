# AlphaGBM Trading Skills

面向 AI agent 的公开投研、财报事件归因、交易复盘与研究沉淀工作流。

**状态：0.2.0 短触发名迁移版。** 当前包含 13 个工作流说明及两个本地辅助脚本，不是完整交易平台。尚无行情/券商/API 集成、回测引擎、收益计算器或自动存档服务；各宿主的真实任务效果仍待验证。单测只验证辅助脚本，不证明研究结论正确或策略有效。

AlphaGBM Trading Skills 不预测价格、不替用户下单、不把相关性包装成因果性。它把研究过程拆成可复核的证据、假设、反证、风险边界和后续结果，尤其适合处理“财报出来后，股价为什么这样走”这类需要多来源核验的问题。

## 核心能力

- **财报与事件归因**：以公司公告/监管披露为事实底座，用电话会、业绩演示和公开市场报道补足语境，区分已证实事实、管理层表述、市场叙事与 agent 推断。
- **预期差拆解**：同时检查 reported、consensus、guidance、关键经营指标和管理层措辞，不以“超预期/不及预期”四个字替代分析。
- **市场反应归因**：明确事件窗口、基准收益、同业/行业对照和宏观混杂因素；输出可证伪的归因，而不是单一故事。
- **研究与决策分层**：研究事实、模型假设、交易计划、实际执行和事后结果分别留痕，避免用结果倒推当时判断质量。
- **隐私与安全**：默认只读；不保存密码、token、完整账户号、真实持仓或私人对话；公开仓库只接受合成样例。

## Skills

品牌仍为 **AlphaGBM Trading Skills**，公开仓库仍为 `AlphaGBM/alphagbm-trading-skills`。`gbm` 只是简短的技能入口，不改变品牌、作者或研究边界。

## 快速触发

记一个入口即可：**`/gbm` + 你想做的事**。知道具体技能时也可直接用 `/gbm-xxx`。

```text
/gbm 财报归因：这家公司公告后为何下跌？
/gbm 研究这家公司的增长质量
/gbm 把已核实的新信息放进三情景估值
/gbm 复盘我的退出是否符合当时规则，只读不保存
/gbm-report 把已有证据整理成内部审阅稿
```

这些是调用示例，不是本仓库提供的斜杠命令解析器。宿主须先发现对应技能；若不支持 `/` 调用，请在技能选择器选择 `gbm`，或明确输入“使用 gbm 技能，帮我……”。裸词 `gbm` 作为入口时先问具体任务；不会自动运行全套技能。`gmb` 不是注册名，不承诺拼错也能触发。

## 证据标准

研究结论必须把每个关键断言绑定到来源、时间戳、原文摘录或可定位段落。默认来源优先级：

1. 监管披露、公司 IR 公告、财报、业绩演示和官方电话会；
2. 交易所/监管机构公开数据和可核验的公司原始文件；
3. 公开市场报道与专业媒体，用于补充市场定价、采访和反应，不替代一手事实；
4. 社交媒体、博客和搜索摘要只能作为线索，不得单独支撑关键结论。

无法取得原文时必须标记 `待核验`，不能把搜索摘要、模型记忆或二手转述写成已确认事实。

## 安装

将所需 `gbm*` 目录与 `_shared` 目录一起复制到宿主指定的 skills 目录，保持它们为同级目录。不要只复制单个 `SKILL.md`，否则共享协议会丢失。若目标目录已有 `_shared`，先人工检查冲突，不覆盖。各 skill 内的共享协议路径均相对于该 skill 的父目录解析。

### 从 0.1.x 升级

本次是技能注册名迁移：`alphagbm` → `gbm`，其余 12 个 `alphagbm-后缀` → `gbm-相同后缀`；完整的新名称见入口清单。仓库地址、品牌和作者不变。

1. 先盘点旧安装目录与个人修改，备份自定义内容和私有记录；不要用通配符删除。
2. 安装对应的新目录和共享协议，更新宿主中的技能路径、收藏及显式调用名。
3. 确认新版可发现后，在宿主中停用旧的这 13 个入口，避免新旧重复命中。仓库不保留双套技能或自动旧名别名。
4. 按宿主要求重新加载技能目录，检查 `gbm` 及所需子技能可选。既有记录内容、记录路径和历史证据不要因技能改名而改写。

本仓库更新不会自动修改你已安装的全局技能；也不会把 `skill-template` 当成第 14 个技能安装。

仓库根目录的 `scripts/` 和 `tests/` 是独立的维护工具，不会随单个 skill 自动安装。不同宿主的发现方式不同，请按宿主说明注册目录；本版本尚未做多宿主端到端兼容验收。

事件案例 CLI 默认拒绝覆盖已有文件；`check` 对真实 `FACT` 要求发布者、文档标题、可访问 URL、发布日期、访问时间、原文定位和原文/数据摘录。空草稿可以通过，加入事实后必须补齐证据。

```bash
python3 scripts/privacy_gate.py
python3 -m unittest discover -s tests -v
```

隐私扫描是启发式辅助检查，不是隐私或密钥安全保证；发布前还须人工审查全部文件及 Git 历史。
