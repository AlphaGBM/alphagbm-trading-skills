# AlphaGBM 概念拆解

## 六段式

一句话定义 → 计算/机制 → 何时有用 → 何时失效 → 常见误解 → 一个带单位和时间窗的合成例子。遇到财报指标必须说明会计口径和非 GAAP 调整。

## 精确性

不把相关性写成因果，不把理论最大损失写成实测风险，不把管理层目标写成已实现结果。用户需要实时数字时转到 `alphagbm-market-research`。
